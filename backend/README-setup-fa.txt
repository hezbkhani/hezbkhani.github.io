این نسخه برای ثبت گزارش امن به Supabase نیاز دارد.
1) پروژه Supabase بسازید و ابتدا schema.sql و سپس update-day-start-azan.sql را در SQL Editor اجرا کنید (روز گزارش از اذان صبح تهران شروع می‌شود).
2) عبارت REPLACE_WITH_ADMIN_EMAIL را با ایمیل مدیر عوض کنید.
3) در Supabase Auth حساب مدیر بسازید.
4) Project URL و anon key را در config.js وارد کنید. فقط anon key عمومی است؛ service role را هرگز در GitHub قرار ندهید.
5) برای ایمیل، Resend API key و دامنه تاییدشده لازم است. تابع daily-report را deploy و با Supabase Cron برای ساعت 06:00 به وقت ایران (02:30 UTC)، یعنی پس از اذان صبح در همه فصل‌ها، زمان‌بندی کنید؛ این تابع گزارش روزِ تمام‌شده را می‌فرستد.
6) تابع نمونه فعلی فقط گزارش‌های تکمیل‌شده را می‌شمارد. برای فهرست افراد تکمیل‌نشده باید فایل‌های گروه یا جدول اعضا نیز در backend همگام شود.

ثبت‌نام دوره جدید و فهرست گروه‌ها در پایگاه داده
7) فایل registration.sql را باز کنید، REPLACE_WITH_ADMIN_EMAIL را با همان ایمیل مدیر عوض کنید و کل آن را در SQL Editor اجرا کنید. (اجرای دوباره بی‌خطر است.)
8) پس از ورود مدیر در ‎/#admin‎ دو بخش تازه دیده می‌شود:
   - «ثبت‌نام دوره جدید»: برای تلگرام یا بله ثبت‌نام باز کنید. با رسیدن به ۱۲۰ نفر ثبت‌نام خودکار بسته می‌شود. سپس «دادن شناسه ۱ تا ۱۲۰» (به ترتیب ثبت‌نام)، تاریخ شروع و شماره گروه را بگذارید و «اعلام» کنید. گروه با همین نام‌ها در فهرست گروه‌ها ساخته می‌شود و متن اعلام برای فرستادن در گروه کپی می‌شود.
   - «فهرست گروه‌ها»: یک‌بار «انتقال گروه‌های فعلی سایت به پایگاه داده» را بزنید؛ از آن پس نام گروه، تاریخ شروع و ۱۲۰ نام هر گروه را همان‌جا ویرایش کنید.
   ثبت‌نام‌کنندگان یک کد پیگیری ۸ رقمی می‌گیرند (روی همان گوشی هم ذخیره می‌شود) و با آن شناسه خود را می‌بینند یا تا پیش از دادن شناسه‌ها انصراف می‌دهند.
9) انتشار برای همه: فعلاً همه این‌ها فقط در ‎/#admin‎ دیده می‌شود. برای انتشار، در registration.js مقدار PREVIEW_ONLY و در app.js مقدار GROUPS_FROM_DB_PREVIEW_ONLY را false کنید. اگر پایگاه داده در دسترس نباشد، سایت همچنان از فایل‌های پوشه groups می‌خواند.
